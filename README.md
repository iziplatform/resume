## ⚡ Architectural Highlights

This repository hosts a production-grade, web-first interactive curriculum vitae engineered with pure web standards (zero bloated build steps, sub-second load times):

- **Dual-Mode Rendering:**
  - **🖥️ Web Screen Mode:** Fluid and responsive. Features a retro-futuristic **"Knowledge Loading" HUD** with real-time quest progress bars (tracking active study in *ArgoCD, CKA, AI Platform Ops*, and *Sony CDJs*).
  - **🖨️ Vector Print Isolation (`@media print`):** Clicking **`Download PDF / Print`** automatically strips the HUD and toolbar, enforcing strict 2-page A4 typography, crisp borders, and full vector fidelity for formal executive review.
- **Enterprise Multi-Cloud Stack:** Highlights 10+ years of enterprise experience across Azure and GCP, 6x Microsoft certifications (Solutions Architect Expert, DevOps Expert, AI Engineer Associate), and self-service platform engineering.
- **Mobile Responsive:** Fluid layout on mobile viewports (< 820px) preventing horizontal scrolling or micro-text, while preserving strict 2-column A4 pagination on desktop and print.
